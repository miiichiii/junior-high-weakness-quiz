# なつやすみノート 🍧

小4の「夏休みのしおり」を、スマホでチェックできるチェックリストにしたものです。
チェックすると絵文字シールがスタンプされ、紙吹雪がはじけます。

**公開URL:** https://miiichiii.github.io/junior-high-weakness-quiz/natsuyasumi-checklist/

## つかいかた

スマホのブラウザで上のURLを開き、ホーム画面に追加するとアプリのように使えます。

- iPhone: 共有ボタン → 「ホーム画面に追加」
- Android: メニュー → 「アプリをインストール」

## できること

| タブ | 中身 |
| --- | --- |
| 🌻 まいにち | 早ね早起き・うがい手洗い・お手つだいなど8項目。日付が変わると自動でリセット |
| 📚 しゅくだい | 必ず取り組むもの①〜⑧。漢字ノートは6冊分を個別にチェック、読書5冊は題名メモ欄つき |
| 🎐 じゆう | 自主学習・作品募集・自由研究など |
| 🎒 9/1のじゅんび | 持ち物16点＋9月1日の時間割＋連絡先（電話番号はタップで発信） |
| 🤝 やくそく | 交通安全・不審者・水の事故・インターネットの使い方 |

そのほか:

- **かき氷ゲージ** — 宿題が進むといちごシロップが上がり、100%でさくらんぼがのります
- **がんばりカレンダー** — その日の「まいにちのやくそく」を全部チェックすると、7/21〜8/31のカレンダーに ◎ スタンプが付きます
- **のこり日数** — 夏休みの残り日数を表示
- 昼／夜のテーマ切り替え、`prefers-reduced-motion` に対応

## しくみ

依存ライブラリなしの単一HTMLファイルです。ビルド作業はありません。

- チェック内容は端末の `localStorage`（キー `natsuyasumi-v1`）に保存されます。サーバーには何も送信しません
- 同じリポジトリのクイズ側は `weaknessQuiz:*` を使うため、記録が混ざることはありません
- そのため、端末やブラウザをまたぐと記録は共有されません
- 記録を消すときは、ページ下部の「きろくを ぜんぶ けす」ボタンから

紙吹雪と花火は Canvas で描画しています。絵文字は端末のフォントをそのまま使うため、
見た目はiOS / Android / PCで少しずつ変わります。

## ファイル

```
index.html              本体（HTML・CSS・JSすべて内包）

icon-*.png              アイコン
apple-touch-icon.png    iOS用アイコン
```

## 内容の出典

小学校第4学年の「夏休みのしおり」（令和8年度）より。
家庭内で使うために作ったものです。学校名・連絡先などは公開リポジトリに載せていません。期間は 2026年7月21日（火）〜8月31日（月）で設定しています。

翌年に使い回すときは `index.html` の以下を書き換えてください。

- `const START` / `const END` — 夏休みの期間
- `const SECTIONS` — チェック項目
- `const RULES` — やくそくの中身
