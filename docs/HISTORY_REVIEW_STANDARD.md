# Challenge社会・歴史 レビュー基準

## 目的

問題が教材の内容に合っているだけでなく、長男が茨城県立下妻第一高等学校の合格圏へ近づく練習になることを基準にする。クイズ単独で合格を保証せず、基礎知識を初見資料へ移す力まで確認する。

## 公式の出題基準

- 茨城県教育委員会「令和7年度茨城県立高等学校入学者選抜実施状況報告書」社会（p.24）
  - 主なできごとと時代背景の理解
  - 図表・地図・統計・年表を読み、比較・関連付け・判断する力
  - 日本と東アジアの関係を、場所と結果を含めて考える力
  - 年代整序と、複数文すべての正誤判断
- 参照: https://kyoiku.pref.ibaraki.jp/wp-content/uploads/2025/06/pdf20250606nljkwerg.pdf

## 単元ごとの作問要件

- 24問: 基本8問、応用8問、直接入力8問。
- 基本: 人物・制度・出来事・文化の最低限の対応を確認する。
- 応用: 少なくとも次を含める。
  - 年代整序または前後関係
  - 原因と結果
  - 二つ以上の制度・条約・時代の比較
  - 初見の年表・地図・関係図の読解（独自図3問）
- 直接入力: 選択肢がなくても重要語句を再生できるか確認する。
- 教材の設問や図版は転載せず、原画像で確認した根拠事項から新しく作る。

## 全問レビュー

作問とは別のレビュー工程で、各問題について次を確認する。

1. 正答と解説が原画像の根拠事項に一致する。
2. 誤答が明確に誤りで、別解や時代条件による解釈の余地がない。
3. 問題文だけから正答が漏れていない。
4. 人名・制度名・条約名・年代・順序・地理的位置が正しい。
5. 単なる語句暗記ではなく、出題技能が単元全体で偏っていない。
6. iPhone幅で図・選択肢・直接入力を操作できる。

## 公開ゲート

- PDF、見開き、左右ページ、印刷ページの対応がすべて一致する。
- 全根拠事項が原画像照合済みで、全問が有効な根拠IDを持つ。
- 自動検査、独立内容レビュー、モバイル表示確認がすべてPASSする。
- 失敗が一つでも残る単元は公開しない。

## 学習後の到達判定

- 別日に直接入力を含め90%前後を再現できる。
- 初見の茨城県型資料問題で80%前後を安定して取れる。
- この二つを満たしたときに「歴史の基礎知識を入試で使える状態」と判定する。
