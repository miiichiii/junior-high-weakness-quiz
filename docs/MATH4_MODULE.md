# 夏休み 算数マスター（小4・ドラッグ計算モジュール）

child-3（小4）向けの、ひきざん（10まで→くり下がりなし→くり下がり）・九九・3桁のかけ算とわり算ひっ算を練習するモジュール。指でタイルをドラッグして計算のマスに数字を置き、くり上がり・くり下がりやくり返しの手順を体で覚える。あわせて、採点しない「らくがきメモ」（手で描くスクラッチパッド）をどの問題でも呼び出せる。

- 学習画面: `math4.html?child=child-3`（`#sub` / `#kuku` を付けると、ひきざん／九九の一覧から開く）
- 実装は2ファイル
  - `math4-core.js`: 画面に依存しない部分（`window.Math4Core`）。出題表・採点と復習スケジュール・ひっ算の盤面・記録の形とマージ。DOM や localStorage には触らない
  - `math4-app.js`: 画面（単一IIFE、`app.js` とは独立）。画面の切りかえ・ドラッグ操作・演出・保存と同期
- 出題データ: ひきざん117問・九九81問は `math4-core.js` で生成（`data/` の外部ファイルなし）。ひっ算は問題をその場でランダム生成する
- 検証: `node scripts/validate-math4.js`（vm で `math4-core.js` を読み、出題表・ひっ算の全盤面・復習スケジュール・マージを確かめる）

## 画面のつながりと「戻る」

```
ホーム（index.html#child-child-3）
  └ メニュー
      ├ ひきざん／九九の一覧 ─ もんだい ─ けっか
      └ ひっ算（かけ算・わり算） ─ もんだい ─ けっか
```

- 戻るボタンは左上の1つだけ。行き先を「← ホーム」「← メニュー」「← ひきざん」「← 九九」のように書く
- 画面ごとに `history.pushState` するので、スマホの「戻る」も同じ順に戻る（`navigate` / `render` / `popstate`）
- けっか画面は もんだい画面を `replaceState` で置きかえる。けっかから戻ると一覧（またはメニュー）で、解き終わった問題には戻らない
- けっか画面の「つぎへ すすむ」「もういちど」も置きかえ（履歴がのびない）
- もんだい・けっかは作り直せない画面なので、別の問題の履歴に来たときは親の画面を出す
- ホームは `index.html#child-child-3`。`app.js` がホームの子どもカードに `id="child-<id>"` を付け、描いたあとでその位置へスクロールする（漢字マスターも同じ行き先）。以前の `index.html?child=child-3` は、リンクのない「受験ロードマップ」画面に飛んでいた

## 楽しく続けるしかけ

- メニュー: 色つきタイル（ひきざん=赤・九九=青・かけ算=緑・わり算=紫）に進みバー（金=マスター、色=クリア）。復習が来ていると「ふくしゅう N」、つぎにやる所に「つぎは ここ」
- ねこ先生のふきだし: あいさつと「つぎは〇〇だよ」、正解・まちがい・ヒント・「はんぶん きたよ」「あと 1もん」などを言う
- もんだい画面: 進みバー、ノーミスが続くと「🔥 Nれんぞく」、3問ごとに声かけ
- ⭐スター（右上）= ノーミスで解けた回数（`Core.starCount`。記録から数えるので保存形式は増やしていない）
- マスターした瞬間に「🏅 〇〇 マスター！」、けっか画面に「あたらしく マスター」の一覧
- けっか画面: ノーミス率でパーフェクト／よくできました／さいごまで できたね、⭐3段階、「つぎへ すすむ」でおすすめの次のグループ（ひっ算は解放された次のレベル）へ

## 学習の流れ

### ひきざん（117問）
学校の順どおり3ステージに積み上げる。③だけ先にやっても身につかないため、①から出す。

| ステージ | 内容 | 問題数 | こたえ | 入力 |
| --- | --- | --- | --- | --- |
| ① 10までの ひきざん | 2−1 〜 10−9 | 45 | 1けた | 1マス |
| ② 10より 大きい かず（くり下がりなし） | 11−1 〜 18−8（ばらから引ける分だけ） | 36 | 2けた | 「10のかたまり」「ばら」の2マス |
| ③ くり下がりの ひきざん | 11−2 〜 18−9（一の位より引く数が大きい） | 36 | 1けた | さくらんぼの①②（2ステップ） |

- 一覧はステージ見出し＋グループ行で、各行は進捗マップを兼ねる。次にやるグループに「つぎは ここ！」
- **グループれんしゅう** = ①図つき → ②図なしの2周
- 図は手順に合わせて動く（`setSubPhase`）
  - ①10まで: `before`（●がm個）→ `after`（b個を×にして残りを光らせる）
  - ②くり下がりなし: `tens`（10のかたまりは くずさない）→ `ones`（ばらから引く）→ `done`
  - ③くり下がり: `split`（ばらが足りない理由）→ `taken`（10から取る）→ `joined`（あわせる）。さくらんぼはSVGの枝で描き、「10」はテンフレームの真上、「ばら」は●の真上に置く
- **きょうのミックス** = 期限が来た復習（最大12問）＋あたらしい問題（1日8問まで、かつ同じグループ内だけ）。新規は図つき、復習は図なし
- 2回まちがえると図が「どう考えるか」の段階から開き、3回目で次の段階＋答えのヒント

### 九九（81問）
- 学校でならう定番順（**2→5→3→4→6→7→8→9→1の段**）に段が並ぶ。各行は進捗マップを兼ねる（グレー=まだ / 青=れんしゅう中 / 緑=クリア / 金=マスター）
- **段れんしゅう** = ①じゅんばんに9問（●の配列図を見ながら）→ ②ばらばらに9問
- **きょうのミックス** = 期限が来た復習（最大14問）+ あたらしい九九（1日9問=1段ぶんまで、段の順）
- 「4 × 7 = □」の空欄に、選択肢タイルをドラッグして入れる。2回まちがえると配列（4行7列の●）を自動で表示する

### 九九・ひきざん共通（`math4-core.js` の問題集エンジン）
- 九九もひきざんも「段階 → グループ → 問題」の同じ形（`makeDrill`）。出題・採点・復習は1つのエンジン（`composeMix` / `composeGroupSession` / `applyFactResult`）
- **マスター = 別の日に2回、ノーミスで正解**。まちがえるとマスターは取り消され翌日に復習が入る。同じ日に2周しても復習予定は1日1回ぶんしか進まない
- ミックスの復習の順: 期限の古い順 → 同じ期限は「いちばん長く見ていない問題」が先（同じ問題が毎日あふれ続けないように）。**前日に練習した問題は上限をこえても必ず出す**（漢字モジュールと同じ）
- 今日のぶんが尽きたら、マスター前の問題を「おかわり」で出す（予定は動かさない）

### かけ算のひっ算
- レベル1「3けた×1けた」→ レベル2「3けた×2けた」の順に解放（レベル1を8問以上・ノーミス率60%以上で次が開く）
- 筆算のマスが右の位から順に光り、数字タイル（0〜9）をドラッグして埋める。くり上がりは小さなマスに別途ドラッグする
- 2けた×の場合は部分積2行→たし算の答え行まで、同じ「1マスずつドラッグ」の流れで最後まで通す

### わり算のひっ算
- 「3けた÷1けた」を出題（商が2桁・3桁になる問題を両方含む）
- 画面は学校の筆算と同じ形（除数 ) 被除数、横線は被除数の上いっぱい、商はその線の上、引き算の線はその計算に使った桁の幅だけ）
- 手順は実際の筆算と同じ「商を1つ立てる→かけた数を下に書く→ひく→つぎの位をおろす」のくり返し。商をぜんぶ先に入力させない（`buildDivisionBoard` は1回ぶんずつ `steps` に積む）
- 「次の位をおろす」操作も、割られる数の数字を直接ドラッグしておろす形で体験する
- ひき算の繰り下がりの筆算そのものは採点対象にせず、「らくがきメモ」で手計算してから結果の数字をドラッグする想定

### らくがきメモ
- どのモードでも「✏️ らくがき」ボタンで呼び出せる、指で自由に描けるキャンバス。採点はしない

## 記録

- `localStorage["weaknessQuiz:child-3:math4Progress"]`（version:1。`facts`=九九ごとの進捗、`subFacts`=ひきざんごとの進捗、`levels`=ひっ算レベルごとの進捗、`daily`=日別サマリー）。`subFacts` や問題ごとの `lastPracticedDay` のように**追加するだけ**のフィールドは、古い記録を壊さないよう version を上げずに `migrateProgress` で既定値を入れる。既存フィールドの意味を変えるときだけ version を上げて移行処理を書く
- 既存の `weaknessQuiz:child-3:stats` の daily にも加算するため、トップ画面の累計・連続日数が自動で反映される
- Google同期は既存の Firestore `records/default` に `math4` フィールドとして相乗り（`merge:true`）。`app.js` の `mergeMath4Progress` は `math4-core.js` の `mergeProgress` と**同じ結果を返すこと**（`app.js` は自分では出題しないが、他端末の記録を上書きしないためにフィールドをラウンドトリップする）。`scripts/validate-math4.js` が乱数の記録60組で両者を突き合わせるので、片方だけ直すと落ちる
- 保護者画面（parent-dashboard.html）と家族ダッシュボード（`family-dashboard-model.js`）に、ひきざん／九九のマスター数・ひっ算の解答数などを表示する

## 問題生成・レベル解放の調整（すべて `math4-core.js`）

- ひきざん: `SUB`（ステージ・グループ・スケジュール）。`kind` が basic / noborrow / borrow のどれかで、出題画面と図の出し方が変わる
- 九九: `KUKU`、段の順番は `DAN_ORDER`
- ひっ算のレベル定義・解放条件は `LEVELS` と `isLevelUnlocked`
- 問題の数値範囲（桁の大きさ、あまりの有無など）は `generateProblem`
- ひっ算のマス配置・ドラッグ手順の順序は `buildMultiplyBoard` / `buildDivisionBoard`（列ごとのくり上がり処理は `buildColumnSteps` に共通化）。行番号を変えるときは `ruleRows` の位置も揃えて直すこと
- `ruleRows` は2つの形を持つ。かけ算は行番号の数値（全幅に線を引く）、わり算は `{row, fromCol, toCol}`（その桁ぶんだけ線を引く）。わり算はグリッドの左端に除数の列を1つ足すため、描画側（`math4-app.js`）の `toGridColumn` が `col + 2` になっている
