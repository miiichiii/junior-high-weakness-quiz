# 夏休み 算数マスター（小4・ドラッグ計算モジュール）

child-3（小4）向けの、ひきざん（10まで→くり下がりなし→くり下がり）・九九・3桁のかけ算とわり算ひっ算を練習するモジュール。指でタイルをドラッグして計算のマスに数字を置き、くり上がり・くり下がりやくり返しの手順を体で覚える。あわせて、採点しない「らくがきメモ」（手で描くスクラッチパッド）をどの問題でも呼び出せる。

- 学習画面: `math4.html?child=child-3`
- 実装: `math4-app.js`（単一IIFE、`app.js` とは独立。`kanji-app.js` と同じ構成）
- 出題データ: ひきざん117問・九九81問はコード内で生成（`data/` の外部ファイルなし）。ひっ算は問題をその場でランダム生成する

## 学習の流れ

4つのモードをホーム画面のカードから選ぶ。

### ひきざん（117問）
学校の順どおり3ステージに積み上げる。③だけ先にやっても身につかないため、①から出す（`SUB_STAGES`）。

| ステージ | 内容 | 問題数 | こたえ | 入力 |
| --- | --- | --- | --- | --- |
| ① 10までの ひきざん | 2−1 〜 10−9 | 45 | 1けた | 1マス |
| ② 10より 大きい かず（くり下がりなし） | 11−1 〜 18−8（ばらから引ける分だけ） | 36 | 2けた | 「10のかたまり」「ばら」の2マス |
| ③ くり下がりの ひきざん | 11−2 〜 18−9（一の位より引く数が大きい） | 36 | 1けた | さくらんぼの①②（2ステップ） |

- ひきざんトップはステージ見出し＋グループ行で、各行は117マスの進捗マップを兼ねる。次にやるグループに「つぎは ここ！」バッジ
- **グループれんしゅう** = ①図つき → ②図なしの2周
- 図は手順に合わせて動く（`setSubPhase`）
  - ①10まで: `before`（●がm個）→ `after`（b個を×にして残りを光らせる）
  - ②くり下がりなし: `tens`（10のかたまりは くずさない、いくつ残る？）→ `ones`（ばらから引く）→ `done`
  - ③くり下がり: `split`（ばらが足りない理由）→ `taken`（10から取る）→ `joined`（あわせる）。さくらんぼはSVGの枝で描き、「10」はテンフレームの真上、「ばら」は●の真上に置く
- **きょうのミックス** = 期限が来た復習（最大12問）＋あたらしい問題（1日8問まで、かつ同じグループ内だけ）。新規は図つき、復習は図なしで出る
- 2回まちがえると図が「どう考えるか」の段階から開き、3回目で次の段階＋答えのヒント
- マスター判定・間隔反復は九九と同じ（別の日に2回ノーミス）。同じ日に2周しても1日1回ぶんしか進まない

### 九九マスター
- 九九トップに、学校でならう定番順（**2→5→3→4→6→7→8→9→1の段**、`DAN_ORDER`）で段が並ぶ。各行は81マスの進捗マップを兼ねる（グレー=まだ / 青=れんしゅう中 / 緑=クリア / 金=マスター）。次にやる段に「つぎは ここ！」バッジが付く
- **段れんしゅう** = ①じゅんばんに9問（●の配列図を見ながら「かたまりの数」として覚える）→ ②ばらばらに9問。同じ日に2周しても、マスター判定・復習予定は1日1回ぶんしか進まない
- **きょうのミックス** = 期限が来た復習（最大14問）+ あたらしい九九（1日9問=1段ぶんまで、段の順に自動供給）
- 「4 × 7 = □」の空欄に、選択肢タイルをドラッグして入れる
- まちがえると赤くゆれて弾かれる。2回まちがえると配列（4行7列の●）を自動で表示する
- **克服（マスター）= 別の日に2回、ノーミスで正解した九九**（既存アプリ・漢字モジュールと同じ「別セッション2回正解」ルール）。まちがえると克服は取り消され翌日に復習が入る

### かけ算のひっ算
- レベル1「3けた×1けた」→ レベル2「3けた×2けた」の順に解放（レベル1を8問以上・ノーミス率60%以上で次が開く）
- 筆算のマスが右の位から順に光り、数字タイル（0〜9）をドラッグして埋める。くり上がりは小さなマスに別途ドラッグする
- 2けた×の場合は部分積2行→たし算の答え行まで、同じ「1マスずつドラッグ」の流れで最後まで通す

### わり算のひっ算
- 「3けた÷1けた」を出題（商が2桁・3桁になる問題を両方含む）
- 画面は学校の筆算と同じ形（除数 ) 被除数、横線は被除数の上いっぱい、商はその線の上、引き算の線はその計算に使った桁の幅だけ）
- 手順は実際の筆算と同じ「商を1つ立てる→かけた数を下に書く→ひく→つぎの位をおろす」のくり返し。商をぜんぶ先に入力させない（`buildDivisionBoard` は1回ぶんずつ `steps` に積む）
- 「次の位をおろす」操作も、割られる数の数字を直接ドラッグしておろす形で体験する
- ひき算の繰り下がりの筆算そのものは採点対象にせず、「らくがきメモ」で手計算してから結果の数字をドラッグする想定（位ごとに正しいマスへ置く練習に絞っている）

### らくがきメモ
- どのモードでも「✏️ らくがき」ボタンで呼び出せる、指で自由に描けるキャンバス。採点はしない。九九の絵図やひっ算の下書きに使う

## 記録

- `localStorage["weaknessQuiz:child-3:math4Progress"]`（version:1。`facts`=九九ごとの進捗、`subFacts`=くり下がりのひきざんごとの進捗、`levels`=ひっ算レベルごとの進捗、`daily`=日別サマリー）。`subFacts` のように**追加するだけ**のフィールドは、古い記録を壊さないよう version を上げずに `migrateProgress` で既定値を入れる。既存フィールドの意味を変えるときだけ version を上げて移行処理を書く
- 既存の `weaknessQuiz:child-3:stats` の daily にも加算するため、トップ画面の累計・連続日数が自動で反映される
- Google同期は既存の Firestore `records/default` に `math4` フィールドとして相乗り（`merge:true`）。`app.js` 側の `mergeMath4Progress` と `math4-app.js` 側は**同一ロジックを保つこと**（`app.js` は自分では九九・ひっ算を出題しないが、他端末の記録を上書きしないためにフィールドをラウンドトリップする）
- 保護者画面（parent-dashboard.html）にひきざん／九九のマスター数・ひっ算レベル別の解答数とノーミス率・今日の学習量を表示する

## 問題生成・レベル解放の調整

- 九九のスケジュール定数は `math4-app.js` の `KUKU_SCHEDULE`、段の順番は `DAN_ORDER`
- ひきざんのスケジュール定数は `SUB_SCHEDULE`、ステージとグループ分けは `SUB_STAGES`（`SUB_FACTS`／`SUB_GROUPS` はそこから自動生成。`kind` が basic / noborrow / borrow のどれかで、出題画面と図の出し方が変わる）
- ひっ算のレベル定義・解放条件は `LEVELS` と `isLevelUnlocked`
- 問題の数値範囲（桁の大きさ、あまりの有無など）は `generateMult1Problem` / `generateMult2Problem` / `generateDiv1Problem`
- ひっ算のマス配置・ドラッグ手順の順序は `buildMultiplyBoard` / `buildDivisionBoard`（列ごとのくり上がり処理は `buildColumnSteps` に共通化）。行番号を変えるときは `ruleRows` の位置も揃えて直すこと
- `ruleRows` は2つの形を持つ。かけ算は行番号の数値（全幅に線を引く）、わり算は `{row, fromCol, toCol}`（その桁ぶんだけ線を引く）。わり算はグリッドの左端に除数の列を1つ足すため、描画側の `toGridColumn` が `col + 2` になっている
